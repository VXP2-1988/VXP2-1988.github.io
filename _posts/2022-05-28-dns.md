I set up a custom domain for my GitHub Pages site yesterday, and this is what I learned.

### Introduction
DNS stands for Domain Name System, and its role is to map IP addresses to human-readable names. For example, running **dig google.com** reveals that **google.com** may be mapped to **108.177.122.139**. Subdomains allow a domain to be divided up into several smaller pieces. For example, the **www** prefix is a subdomain of **logans.page**. Custom subdomains can be added, like **blog.logans.page**, or **store.logans.page**. This website is set up to serve the main blog at the apex domain and redirects the **www** subdomain to the apex automatically.

### CNAME (Canonical Name)
A CNAME record allows one domain name to alias another. For example, **old.site.com** can redirect to **new.site.com** or **www.site.com** can redirect to **site.com**. They're commonly used to point one website or service to another, like pointing a subdomain to a based domain. The records can redirect anywhere, with some restrictions. 

CNAME can not redirect the root directory, since the root domain is the start of a DNS address (SOA start of authority) and cannot be aliased. For example, the CNAME record type cannot be used to point **logans.page** to **loganagol.github.io** since **logans.page** is the root/apex, but it can be used to point **www.logans.page** to **loganagol.github.io**. 

Some DNS providers allow a wildcard subdomain, such as **\*.logans.page**. This is not recommended for GitHub pages because it allows anyone to host a webpage on your subdomain with GitHub.

### A (Host Address)
This restriction on redirecting the root directory does not apply to the A record. The A record is more basic and directly translates a domain name to an IP address, as opposed to the CNAME which translates a domain name to another domain name.

An A record can be setup to direct a root domain name to one or more IP addresses. In this case, the domain name **logans.page** is setup to point to the list of GH Pages CDN IP addresses. When the client requests the webpage, the DNS server returns the IP address of the GH pages CDN server, which then delivers the GH page that I've linked to this domain.

The AAAA address type is similar, and applies to IPv6 addresses.
